# Blazor DataGrid PDF Export

Export data from the [Blazor DataGrid](https://www.syncfusion.com/blazor-components/blazor-datagrid) component to PDF with comprehensive customization options. This project demonstrates essential and advanced techniques for converting grid data into formatted PDF documents.

## Overview

The Blazor DataGrid is a powerful component for displaying and managing tabular data. This project showcases how to leverage its built-in PDF export functionality to generate professional reports and documents directly from your grid data.

## Features

- **Basic PDF Export** — One-click export of grid data to PDF
- **Header & Footer Customization** — Add titles, branding, and footer information
- **Column Customization** — Control column visibility and formatting in exports
- **Row Styling** — Apply custom styling to specific rows
- **Cell Formatting** — Customize individual cell appearance and content
- **Header Cell Styling** — Format header rows with custom styles and colors
- **Filename Customization** — Dynamically set export filenames
- **Data Source Customization** — Export filtered or transformed data
- **Group Customization** — Style and format grouped data exports
- **Aggregate Customization** — Include calculated aggregates in exports

## Prerequisites

* [.NET SDK 10.0](https://dotnet.microsoft.com/en-us/download/dotnet/10.0) or later
* [Visual Studio 2022](https://visualstudio.microsoft.com/vs/) or later
* [Visual Studio Code](https://code.visualstudio.com/)

## Getting Started

### Clone the repository

```bash
git clone https://github.com/SyncfusionExamples/Export-Blazor-DataGrid-to-PDF.git
cd Export-Blazor-DataGrid-to-PDF
```

### Run with Visual Studio

1. Open the solution file using Visual Studio 2022 or later.
2. Restore the NuGet packages by rebuilding the solution.
3. Build the project to ensure there are no compilation errors.
4. Run the project.

### Run with .NET CLI

```bash
# Restore dependencies
dotnet restore

# Run the project
dotnet run
```
